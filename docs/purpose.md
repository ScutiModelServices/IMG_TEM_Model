# Purpose

**Kind:** class label → image

**Group:** Image Generation

**Tags:** `gpu`, `license-restricted`

| | |
|---|---|
| Input | An ImageNet class id or label (1000 classes), steps, step size, seed. No text prompts. |
| Output | 256×256 PNG. Same seed gives same image. |
| Runs on | NVIDIA GPU (~4 GB VRAM, ~6.8 s per image). |

**Use for:** placeholder, demo and test images by class.
**Not for:** free-text prompts, anything outside the 1000 classes. No stated licence: own projects only.
